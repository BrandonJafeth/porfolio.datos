## Método

Tomé el <Termino t="tipo de cambio" /> de venta diario y lo resumí por mes.
Después comparé cada mes contra el <Termino t="promedio" /> de su propio año.
Así se ve la <Termino t="estacionalidad" /> sin que la tendencia de largo plazo la tape.

### 1. Promedio mensual en SQL

```sql
-- Tipo de cambio de venta: promedio por año y mes
SELECT
  EXTRACT(YEAR  FROM fecha) AS anio,
  EXTRACT(MONTH FROM fecha) AS mes,
  AVG(venta)                AS venta_promedio
FROM tipo_cambio
WHERE fecha BETWEEN DATE '2021-01-01' AND DATE '2025-12-31'
GROUP BY 1, 2
ORDER BY 1, 2;
```

### 2. Diferencia contra el promedio del año en Python

```python
import pandas as pd

mensual = pd.read_sql(QUERY, conexion)
mensual["desvio"] = (
    mensual["venta_promedio"]
    - mensual.groupby("anio")["venta_promedio"].transform("mean")
)
patron = mensual.groupby("mes")["desvio"].mean().round(1)
patron.to_json("estacionalidad.json")  # este sitio solo lee el resultado
```
